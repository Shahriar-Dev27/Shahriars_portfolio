## Asset policy

- Keep the declared aspect ratios for any final replacements (hero 1067×1402, statement 800×1000 — same ratio as the original 1122×1402 master, BizGuide AI 1600×743). Match project image metadata and preview framing to each screenshot's actual dimensions.
- New raster images ship as WebP, generated by `scripts/optimize-images.mjs`. Keep the PNG master alongside but reference only the `.webp` file.
- Keep lower-page images lazy-loaded (`loading="lazy"`, `decoding="async"`).
- Replace generated or temporary imagery with honest project screenshots or final editorial photography before launch. Do not use random online imagery.
